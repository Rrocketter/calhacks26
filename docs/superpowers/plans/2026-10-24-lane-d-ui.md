# Lane D: HUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the voice lane's bare page with the judge-facing HUD (top bar counters, transcript, belief, executor with state stepper and diff view), driven either by the live `/ws` server or by an in-browser mock socket that replays the `packages/contracts/mocks` utterance-1 fixtures.

**Architecture:** Every server event, live or mock, goes through one pure reducer (`hudReducer`) that owns all HUD state; React components only render that state. Two transports share one interface: `startLive` (the voice lane's WS + mic capture + `PcmPlayer`, moved out of `App.tsx` unchanged in behavior) and `MockSocket` (composes `mockInkStream`, `mockBeliefStream`, `mockDroidRun` and synthesizes the `state_change` events Lane C's state machine would send). Mock mode is chosen with `?mock=1`.

**Tech Stack:** Vite 8 + React 19 + TypeScript, `@ahead/contracts` (schema, types, browser-safe mocks), vitest 4.1.12 (same pin as contracts, already in the lockfile; added to `apps/web` devDependencies, needs human OK). Plain CSS, system fonts, no UI libraries.

**Spec:** `docs/lanes/ui.md` (brief), the human's Lane D prompt (extra requirements, quoted in Global Constraints), `PLAN.md` sections 4 and 5, `docs/sdk-notes.md` "Summary for lanes" and the Executor "STAGED when the edit lands" section.

## Global Constraints

- Only touch `apps/web` (plus this plan). Never edit `packages/contracts`; import only from `@ahead/contracts` and `@ahead/contracts/mocks`. No imports from `apps/server`.
- Keep `src/audio/capture.ts`, `src/audio/playback.ts`, `src/audio/base64.ts`, `public/pcm-capture-worklet.js` as they are.
- Mock data only in mock mode (`?mock=1`). Live mode (default) never shows fixture data. The top bar shows a `MOCK` badge in mock mode.
- Every mock event is round-tripped through `parseServerEvent(JSON.stringify(e))` before it reaches the reducer, so mock mode is schema-checked like live mode.
- Read `failed` on result payloads defensively: `(payload as {failed?: boolean}).failed === true` (contracts' `DroidResultPayload` has no `failed`).
- Layout: dark, exactly one accent color (`--accent: #f5b700`); red (`--bad: #ff4d4f`) only for denied / stale / rolled back; monospace (`ui-monospace, SFMono-Regular, Menlo, monospace`) with `font-variant-numeric: tabular-nums` for every number. No page scrolling at 1440x900 (`html, body, #root { height: 100%; overflow: hidden }`; panels clip). Legible from 4 feet: body text ≥ 18px, partial transcript ≥ 32px, intent label ≥ 44px.
- Stepper order exactly `LISTENING → BELIEF_FORMING → SPECULATING → STAGED → COMMITTED | ROLLED_BACK` (last slot shows whichever outcome happened).
- Top bar: "Moss queries this turn" (count), "avg retrieval ms" (1 decimal), "time to first audio" (client TTFA, else server `metric` sonic `ttfa`, else `-`).
- Interject trigger word stays highlighted in the transcript, including after the turn finalizes and moves to the finals list.
- `pnpm -r build`, `pnpm -r lint`, `pnpm --filter @ahead/web test` pass at the end of every task. One commit per task, conventional commits, never push.

## Review Focus

1. Late events for an older turn (the final Haiku belief lands 1.2 to 1.7 s after `transcript_final`, possibly after the next `turn_start`) → `belief_update` / `moss_hits` whose `turnId` is not the current turn are ignored. Test in Task 1.
2. Ink normalizes text ("Thursday," with punctuation, different case) or the interject lands before the trigger word is in the partial → the word is matched case- and punctuation-insensitively, and resolved on a later partial if not yet present. Test in Task 1.
3. Malformed droid payloads (`plan.steps` not an array, `result` without `summary`) → ignored field by field, never a crash. Test in Task 1.
4. Replay restarted while one is running, or socket closed mid-replay → no events from the old run after `close()`. Test in Task 2.
5. Long content (many tools, long diff, many finals) → page still does not scroll at 1440x900; panels clip internally. Checked in Task 5 with `document.documentElement.scrollHeight <= innerHeight`.

### Task 1: HUD reducer + test harness

**Files:**

**Interfaces:**
- Consumes: `ServerEvent`, `Belief`, `State`, `MossHit` from `@ahead/contracts`.
- Produces:
```ts
export type ToolCall = { tool: string; path?: string; denied: boolean; reason?: string };
export type DroidResult = { ok: boolean; summary: string; failed: boolean };
export type FinalLine = { turnId: string; text: string; highlight: number | null };
export type Interject = { turnId: string; text: string; said: string | null; wordIndex: number | null };
export type HudState = {
  turnId: string | null;           // current turn (turn_start)
  partial: string;
  eagerEnd: boolean;               // turn_eager_end seen, cleared by turn_resume / turn_start
  finals: FinalLine[];             // last 3
  interject: Interject | null;     // cleared at next turn_start; the highlight survives in finals
  belief: Belief | null;
  moss: { count: number; totalMs: number; lastMs: number | null }; // reset at turn_start
  stateTurnId: string | null;
  state: State;                    // starts 'LISTENING'
  reached: State[];                // states seen for stateTurnId, in arrival order, no duplicates
  droidTurnId: string | null;
  plan: string[];
  steps: string[];
  tools: ToolCall[];
  diffs: { file: string; diff: string }[]; // one per file, a repeat replaces in place
  result: DroidResult | null;
  ttfa: { client?: number; server?: number }; // reset at turn_end
  error: string | null;
};
export type HudAction = ServerEvent | { type: 'client_ttfa'; ms: number } | { type: 'reset' };
export function initialHud(): HudState;
export function hudReducer(s: HudState, a: HudAction): HudState;
export function words(text: string): string[];            // split on whitespace, empty-safe
export function findWord(text: string, said: string): number | null; // index into words(text) of the first token equal to `said` after lowercasing and stripping non-alphanumerics, else null
```

Rules the tests pin:
- `turn_start` sets `turnId`, clears `partial`, `eagerEnd`, `interject`, `moss`; keeps `finals`, belief, executor fields.
- `belief_update` / `moss_hits` with `turnId !== s.turnId` (when `s.turnId` is set) are ignored. `moss_hits` adds 1 to `count`, `latencyMs` to `totalMs`, sets `lastMs`.
- `interject`: `said` = `s.belief?.claims[0]?.said ?? null`; `wordIndex` = `findWord(s.partial, said)`, or the last word index of `s.partial` when `said` is null. Each later `transcript_partial`/`transcript_final` of that turn resolves a null `wordIndex` via `findWord`.
- `transcript_final` pushes `{turnId, text, highlight}` (highlight = interject `wordIndex` when the interject is for that turn) and clears `partial`.
- `state_change` with a new `turnId` resets `reached` to `[state]`; same turn appends if not present.
- `droid_event` with a new `turnId` resets `plan, steps, tools, diffs, result` before applying. `plan` replaces `plan` when `payload.steps` is a string array; `step` appends `payload.text` when a string; `tool` appends `{tool, path, reason, denied: e.denied === true || payload.denied === true}`; `diff` upserts by `file`; `result` sets `{ok: payload.ok === true, summary: typeof summary === 'string' ? summary : '', failed: payload.failed === true}`.
- `metric` sonic `ttfa` sets `ttfa.server`; `client_ttfa` sets `ttfa.client`; `turn_end` clears `ttfa`; `error` sets `error` as `` `${source ?? 'server'}: ${message}` ``; `reset` returns `initialHud()`.

### Task 2: Mock socket replaying contracts mocks

**Files:**
- Create: `apps/web/src/transport.ts`, `apps/web/src/mock/socket.ts`, `apps/web/src/mock/socket.test.ts`

**Interfaces:**
- Consumes: `mockInkStream`, `mockBeliefStream`, `mockDroidRun`, `InkFixture` from `@ahead/contracts/mocks`; fixture JSON via `import fixture from '@ahead/contracts/mocks/fixtures/demo-utterance-1.json'`; `parseServerEvent`.
- Produces:
```ts
// transport.ts
export interface Transport { send(ev: ClientEvent): void; stop(): void }
// mock/socket.ts
export type ReplayOpts = { speed?: number; denied?: boolean; failed?: boolean; autoConfirmMs?: number | null };
export const BELIEF_OFFSET_MS = 600;
export class MockSocket implements Transport {
  constructor(onEvent: (e: ServerEvent) => void, opts?: ReplayOpts);
  play(): Promise<void>;          // one full replay; resolves when done or stopped; a second play() stops the first
  send(ev: ClientEvent): void;    // confirm_action → state_change COMMITTED (apply) / ROLLED_BACK; demo_control start → play(), stop → stop()
  stop(): void;                   // no events after this returns
}
```

Replay order (speed 1, `turnId` from the fixture, `demo-1`):
- Ink stream runs from t=0. On its `turn_start` emit `state_change LISTENING`, then start the belief stream `BELIEF_OFFSET_MS` later (so the Thursday interject lands after the Thursday partial at 3000 ms and before "at" at 3250 ms; the mocks' own timelines are otherwise misaligned).
- First `belief_update` → `state_change BELIEF_FORMING`. First belief with `confidence >= 0.75` and intent in `reschedule_event | draft_message | find_file | add_note` → `state_change SPECULATING`, start `mockDroidRun(turnId, {withDenied: opts.denied})`.
- Droid `plan`/`step`/`tool` pass through as they come; `diff` and `result` are held until `turn_eager_end` has been emitted (Phase 2). The first released `diff` is followed by `state_change STAGED`. With `opts.failed`, the `result` payload becomes `{ok:false, failed:true, summary:'droid turn failed after staging'}`.
- After `turn_end` emit `metric {source:'sonic', label:'ttfa', ms: 180}`. When both `turn_end` and STAGED have happened and `autoConfirmMs` is not null (default 1500), emit `state_change COMMITTED` after that delay (stands in for the spoken "yes").
- Every event goes through `parseServerEvent(JSON.stringify(e))`; on `null`, emit `{type:'error', source:'mock', message:'invalid mock event <type>'}` instead.
- Timers scale by `1/speed` (pass `speed` to the mocks too).
