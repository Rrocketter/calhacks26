# Lane C Executor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `Speculator` in `apps/server` that turns a locked belief into staged, reversible, visible work in `~/.ahead/workspace` via the Factory Droid SDK, using two-phase speculation on a `spec/<turnId>` branch with commit (fast-forward) and rollback (branch delete).

**Architecture:** A pure `StateMachine` (`transition(ctx, event) -> {ctx, effects}`) decides what happens; a `Speculator` feeds it `ServerEvent`s plus `confirm_action` and runs its effects against an `Executor` interface. `DroidExecutor` implements `Executor` with one warm Droid session per turn (sandbox, tool allowlist, child env allowlist, watchdog, write-only permission handler, all ported from `apps/server/scripts/spike-droid.ts`) and a `WorkspaceGit` helper for branch, reset, diff, merge and delete. Everything below the Speculator is injected so unit tests use fakes, `mockBeliefStream` and `mockDroidRun`; one live smoke script proves the real path.

**Tech Stack:** Node 20.19, TypeScript 6.0.3 (NodeNext ESM, `.js` import suffixes), `@factory/droid-sdk@0.10.0` (`@factory/droid-sdk/node`), `@ahead/contracts` (zod schema + mocks), `node:test` via `node --import tsx --test`, system `git`.

**Spec:** `PLAN.md` (section 4 speculation rules, section 5 utterances 2 and 3), `docs/lanes/executor.md`, `docs/sdk-notes.md` (Summary for lanes, Factory Droid SDK, Confinement, Lane C rule), `apps/server/scripts/spike-droid.ts`.

## Global Constraints

- Do not edit `packages/contracts`. If the schema cannot express something, stop and report to the human.
- No new dependencies. Imports across apps only via `@ahead/contracts`.
- Droid confinement, copied exactly from the spike:
  - `disabledToolIds`: `Execute, Script, FetchUrl, WebSearch, LS, Glob, Grep, Task, Skill, ConnectApp, StageSettingsChanges, ListAutomations, ReadAutomation, ListAutomationTemplates`.
  - After `updateSettings({ enabledToolIds: ['Create','Edit','ApplyPatch'] })`, `listTools()` allowed set must equal exactly `Create, Edit, Read, TodoWrite, ToolSearch` (+ `ApplyPatch` only if offered), else close and throw.
  - `autonomyLevel: AutonomyLevel.Off`, `modelId: 'claude-haiku-5-5'`, `cwd: WORKSPACE_DIR`.
  - Sandbox settings file via `execArgs: ['--settings', file]`: `{sandbox:{enabled:true, mode:'per-command', filesystem:{denyRead:[realpath($HOME), ...repo spellings, ~/.ssh, ~/.aws, ~/.config, ~/.netrc, ~/.npmrc, ~/.gnupg, ~/.factory], allowRead:[realpath(workspace)], denyWrite:[<workspace>/.git, ...repo spellings]}}}`.
  - `session.settings.sandbox.enabled` must be `true` before the first prompt; otherwise close the session and throw `Error('droid sandbox disabled')`. No env flag turns this off.
  - Child env: `droidChildEnv()` (allowlist `FACTORY_API_KEY, PATH, HOME, TMPDIR, LANG, USER, SHELL`, every other key `undefined`).
  - Watchdog: on a tool name outside `Read, Create, Edit, ApplyPatch, TodoWrite, ToolSearch`, or any path outside the workspace (no Create/Edit exemption in the product), emit `droid_event kind:'tool' denied:true payload:{tool, path, denied:true, reason}`, `interrupt()`, wait up to 1500 ms for the turn's `result`, then `close()`.
  - Permission handler gates writes only: `ProceedOnce` for create/edit/apply_patch whose every path is inside the workspace, `Cancel` otherwise; each deny emits the denied `droid_event`. A `sandbox_violation` confirmation is classified from `details.violationType` (structured), reason `sandbox-<violationType>`.
- Refuse to run if `WORKSPACE_DIR` is inside `REPO_ROOT` or `REPO_ROOT` is inside it (sdk-notes Summary, Droid line).
- At most two prompts per session in the normal path (Phase 1, Phase 2); a re-sent Phase 2 after `turn.resume` is the only exception (PLAN.md line 94). At most one live speculation per turn.
- Lock threshold `confidence >= 0.75` and intent in `reschedule_event | draft_message | find_file | add_note` (`lookup` never dispatches Droid).
- Branch `spec/<turnId>`; turnId sanitized to `[A-Za-z0-9._-]`. COMMIT = `merge --ff-only` into `main` then delete the branch. ROLLBACK = interrupt, close, `checkout -f main`, `clean -fd`, `branch -D`.
- Server-side git runs with `-c core.hooksPath=/dev/null -c user.name=ahead -c user.email=ahead@localhost -c commit.gpgsign=false` and an env with `GIT_*` keys removed (same as `scripts/reset-workspace.mjs`).
- Log every external call with latency, format `[droid] <label> <ms>ms` via `logLatency('droid', ...)` from `apps/server/src/log.ts`, and emit `{type:'metric', source:'droid', label, ms}` for: `createSession`, `phase1`, `phase2`, `diff`, `commit`, `rollback`.
- Never print model text, tool result bodies or env values; lengths and booleans only (spike rule).
- Every emitted `ServerEvent` must pass `parseServerEvent(JSON.stringify(ev))`; tests assert it.

## Review Focus

1. Belief confidence flapping around 0.75 across updates (0.78, 0.74, 0.79, same intent) must dispatch Phase 1 exactly once. Test in Task 3.
2. Ink can send `turn.end` without a prior `turn.eager_end`; Phase 2 must then be sent at `turn_end`. Test in Task 3.
3. User says "yes" (`confirm_action apply:true`) while Phase 2 is still running: commit once STAGED, not drop it. Test in Task 3.
4. A crashed earlier run leaves the workspace dirty or on a stale `spec/*` branch: `prepare` must start from clean `main`. Test in Task 4.
5. The Droid session dies mid-phase (watchdog close, CLI exit, stream throws): speculation ends ROLLED_BACK, workspace clean, and the next turn gets a fresh warm session. Test in Task 7.

export type Emit = (ev: ServerEvent) => void;

  phase1(turnId: string, belief: Belief): Promise<void>; // prepare branch + Phase 1 prompt

  rollback(turnId: string): Promise<void>;
}

  stream(prompt: string, opts?: { includePartialMessages?: boolean }): AsyncIterable<DroidStreamEvent>;
  interrupt(): Promise<void>;
  close(): Promise<void>;
}

```ts
export const LOCK_CONFIDENCE = 0.75;
export const SPECULATIVE: readonly Intent[] = ['reschedule_event','draft_message','find_file','add_note'];
export type SmEvent =
  | { type: 'turn_start'; turnId: string }
  | { type: 'belief'; belief: Belief }
  | { type: 'eager_end' } | { type: 'resume' }
  | { type: 'turn_end'; belief: Belief | null }   // latest belief at turn end
  | { type: 'phase2_done' } | { type: 'failed' }
  | { type: 'confirm'; apply: boolean };
export type Effect =
  | { type: 'phase1'; belief: Belief } | { type: 'phase2'; belief: Belief }
  | { type: 'reset_phase1' } | { type: 'commit' } | { type: 'rollback' } | { type: 'warm' }
  | { type: 'state'; state: State };
export type SmCtx = { turnId: string|null; state: State; locked: Belief|null; latest: Belief|null;
  phase2Sent: boolean; turnEnded: boolean; pendingApply: boolean|null };
export function initial(): SmCtx;
export function transition(ctx: SmCtx, ev: SmEvent): { ctx: SmCtx; effects: Effect[] };
```
